# AutoFire — Operator's Playbook

Everything you need to set up, run and grow the agency. Read in this order:

1. **[RUNBOOK.md](./RUNBOOK.md)** — get the site live and the business switched on (do this first).
2. **[DELIVERY.md](./DELIVERY.md)** — how to actually build the 5 core automations you sell.
3. **[OUTREACH.md](./OUTREACH.md)** — copy-paste DM / email / audit scripts to get clients.
4. **[CONTENT-CALENDAR.md](./CONTENT-CALENDAR.md)** — 30-day content plan + Reel/Short scripts.
5. **[OPERATIONS.md](./OPERATIONS.md)** — pricing, payments, contracts, onboarding, tools.

> The website is the storefront. **Clients come from outreach + content** (docs 3 & 4).
> Spend ~70% of your time there, not tweaking the site.

## The 90-day goal
- **Weeks 1–2:** site live, tools learned, build 2–3 demo automations, start outreach.
- **Weeks 3–4:** close 1–2 paying clients ($500–$2k), post daily.
- **Months 2–3:** 3–5 clients + first retainers, turn deliveries into case studies.
